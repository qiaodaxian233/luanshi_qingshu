# 🎭 乔大仙 · 全能助手(项目联动版)

一个功能强大的用户脚本，为 ChatGPT、OpenAI 等 AI 对话平台提供增强功能。

## 功能特性

### v6.1.0 版本
- **配置导入/导出**: 支持整体备份和跨设备同步

### v6.0.2 版本
- **TXT 剧本上传**: 上传的 TXT 剧本也作为附件传递给 GPT

### v6.0.1 版本
- **项目标签风格**: 提示词支持自定义

### v6.0 版本
- **TXT 剧本处理**: 自动提取人名 → 匹配角色图 + 提示词，一键应用

## 主要模块

- **提示词管理**: 收藏、自定义、分类搜索
- **图片下载**: 自动命名、批量下载、历史记录
- **图片上传**: 高清修复、人脸修复、细节优化
- **角色参考图**: 多张图片库、多选功能
- **项目模块**: TXT 剧本处理、角色匹配、提示词应用

## 安装使用

1. 安装用户脚本管理器（如 Tampermonkey、Violentmonkey）
2. 安装此脚本
3. 访问支持的网站（ChatGPT、OpenAI 等）
4. 使用脚本提供的增强功能

## 支持的网站

- https://chatgpt.com/
- https://chat.openai.com/
- https://gpt.aimonkey.plus/
